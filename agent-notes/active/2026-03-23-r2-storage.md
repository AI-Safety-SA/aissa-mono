## Objective and Scope

**In scope**: payload config, env example, migration script.
**Out of scope**: package.json changes (already done), actual R2 bucket setup, DNS/public URL config.

## Implementation Log

1. **`apps/track-record/src/payload.config.ts`** — Replaced `uploadthingStorage` import/plugin with `s3Storage` from `@payloadcms/storage-s3`. Config uses `R2_BUCKET`, `R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` env vars.

2. **`apps/track-record/.env.example`** — Removed `UPLOADTHING_TOKEN`, added R2 vars with comments.

3. **`apps/track-record/scripts/migrate-media-to-r2.ts`** — New migration script. Uses `getPayload` to iterate all media docs, downloads from UploadThing URLs, uploads to R2 via `@aws-sdk/client-s3`. Idempotent (HeadObjectCommand check). Handles size variants defensively. Run with `npx tsx scripts/migrate-media-to-r2.ts`.
