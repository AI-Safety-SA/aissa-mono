# Issue tracker: Linear

Issues and PRDs for this repo live in Linear. Use the Linear connector when it is available, or the team's normal Linear workflow if connector access is not configured.

## Conventions

- Create issues and PRDs in Linear for the AISSA monorepo.
- Read existing issues from Linear before refining, triaging, or implementing work.
- Use the triage label vocabulary in `docs/agents/triage-labels.md` when applying labels or equivalent Linear metadata.
- Link back to relevant code, PRs, and notes from Linear issues when useful.

## When a skill says "publish to the issue tracker"

Create a Linear issue.

## When a skill says "fetch the relevant ticket"

Fetch the referenced Linear issue, including its description, comments, labels, status, and linked work when available.
